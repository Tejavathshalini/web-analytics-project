# Web Analytics Project (GA4 + Looker Studio)

## 🔍 Project Overview
A self-initiated web analytics project to track user behavior on a live website using Google Analytics 4 (GA4) and visualize insights using Looker Studio.

## 🧰 Tech Stack
- Google Analytics 4 (GA4)
- Looker Studio (Dashboarding)
- HTML, CSS, JavaScript (basic website)
- GitHub Pages (hosting)

## 📊 What I Implemented
- Integrated GA4 tracking on a live website
- Verified real-time user activity and page views
- Enabled enhanced measurement for scrolls and interactions
- Designed a Looker Studio dashboard to visualize:
  - Total users
  - Page views
  - Traffic sources
  - Views by page
